Library Management System

📚 Project Overview

The Library Management System is a C++ application used to manage books, library members, and book transactions such as issuing and returning books.

✨ Features

- Add books
- Remove books
- Search books
- Display all books
- Add library members
- Display members
- Issue books
- Return books
- Store data using ".txt" files

🛠️ Technologies Used

- C++
- Object-Oriented Programming (OOP)
- File Handling
- STL

▶️ How to Run

1. Clone this repository.
2. Open the project in Eclipse or another C++ IDE.
3. Make sure the "data" folder is present.
4. Compile the C++ source files.
5. Run "main.cpp".

💾 Data Storage

The application stores library information in text files:

- "books.txt" — Book information
- "members.txt" — Member information
- "transactions.txt" — Issue/return history
- "issued.txt" — Currently issued books
